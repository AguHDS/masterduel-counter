# Master Duel Counter

**Master Duel Counter** is a plataform that is designed to help users to create they own guides for the specific tradding card games.

## Main Features

* Counter Guides / Deck Guides
* Guide Request Feature
* Tierlist
* Card Search
* User profile
* Personal deck builder
* Save guides as favorites
* Notifications
* Ranking system
* Report system
* Admin panel

## General Tech Stack

* **Node.js / Express**
* **Better-SQLite3**
* **Better Auth**
* **Prisma**
* **Cloudinary**
* **React**
* **Vitest**
* **Tailwind CSS**
* **TanStack Query**
* **Axios**
* **Docker**
* **Terraform**
